# 🎮 Number Guessing Game

A fun and interactive number guessing game built with Python.

## 🚀 Features
- Random number generation between 1-20
- User feedback system (higher/lower hints)
- Attempt tracking and statistics
- Best score recording
- Input validation
- Play again option

## 📦 Installation
```bash
git clone https://github.com/kamankeshalireza30-cloud/number-guessing-game.git
cd number-guessing-game
python game.py
